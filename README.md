SCT_DS_1 - Population Distribution Visualization
About the Project
This project was completed as part of the SkillCraft Technology Data Science Internship.
The goal of this task was to create a visualization showing the distribution of a variable using a bar chart or histogram. For this project, I used the World Bank Population Dataset and created a bar chart displaying the top 10 most populous countries in 2022.
Tools and Technologies Used
•	Python
•	Pandas
•	Matplotlib
Dataset
World Bank Population Dataset
What I Did
•	Loaded the dataset using Pandas.
•	Cleaned and filtered the required data.
•	Selected population data for the year 2022.
•	Identified the top 10 most populous countries.
•	Created a bar chart to visualize the population distribution.
•	Saved the chart as an image for presentation.
Outcome
The final visualization provides a clear comparison of the population sizes of the top 10 most populous countries in 2022. This task helped me gain hands-on experience in data handling, data cleaning, and data visualization using Python.
